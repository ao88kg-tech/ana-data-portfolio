# Ana Karen Ortega Gómez - Data Analytics Portfolio

Portafolio profesional enfocado en análisis de datos, visualización e insights de negocio.

## Sobre mí

Soy arquitecta de formación y recientemente completé un bootcamp de Análisis de Datos. Me interesa utilizar datos para resolver problemas, identificar oportunidades y apoyar la toma de decisiones mediante análisis claros y accionables.

## Proyectos Destacados

### Airbnb Market Analysis
Análisis exploratorio del mercado de Airbnb en Nueva York para identificar factores que influyen en el precio y la popularidad de los alojamientos.

### Superstore Sales Performance Analysis
Análisis de ventas y rentabilidad para identificar categorías, regiones y productos con mayor impacto en el desempeño del negocio.
